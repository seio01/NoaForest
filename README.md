## 프로젝트 소개

| 항목 | 내용 |
|---|---|
| 장르 | 캐주얼 2D 머지 디펜스 |
| 플랫폼 | Android |
| 개발 환경 | Unity 2022.3.62f2 · C# |

불안정한 원소 파편 ‘모트’를 정화하기 위해 탄생한 수호자 ‘노아’를 소환하고 성장시키는 게임입니다.

## 주요 기능

- 상태 기반 웨이브 및 정화 시스템
- 노아 소환·합성 및 수집·성장
- Firebase 인증 및 사용자 데이터 연동

## Tech Stack

- Unity · C#
- URP 2D
- Firebase Authentication · Firestore · Cloud Functions
- Google Sign-In
- DOTween Pro · Odin Inspector · Newtonsoft.Json
- Android · IL2CPP · ARM64
