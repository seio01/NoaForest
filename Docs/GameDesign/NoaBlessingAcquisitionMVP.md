# 노아·정화 가호 획득 시스템 MVP 기획

- 문서 상태: Draft v0.1
- 작성일: 2026-07-29
- 대상 콘텐츠: 노아 도감, 정화, 가호의 제단, 정화 가호 강화
- 관련 문서: `PurifyRewardBalance.md`

## 1. 목적

노아와 정화 가호를 처음부터 모두 사용할 수 있는 구조에서 정화 플레이를 통해 순차적으로 획득하는 구조로 변경한다.

정화를 반복해야 하는 장기 목표를 제공하되, MVP에서는 천장·집중 소환·교환소 등의 보완 시스템을 제외하여 규칙과 구현 범위를 단순하게 유지한다.

## 2. 핵심 결정

### 노아

- 모든 1단계 노아는 기본 해금 상태로 시작한다.
- 2단계와 3단계 노아는 `노아의 기억`을 사용하여 해금한다.
- 노아는 합성 계보와 동일하게 1단계 → 2단계 → 3단계 순서로만 해금할 수 있다.
- 미해금 노아는 정화 소환 풀과 합성 결과에서 제외한다.
- 노아를 해금하면 정화 소환 풀과 합성 결과에 즉시 추가한다.

### 정화 가호

- 정화를 통해 가칭 `정화 가호 소환 티켓`을 획득한다.
- 티켓은 `가호의 제단`에서 가호를 소환할 때 사용한다.
- 가호를 처음 획득하면 해당 가호를 Lv.1로 해금한다.
- 이미 해금한 가호를 중복 획득하면 해당 가호의 전용 조각 1개를 획득한다.
- 가호 레벨업에는 레벨별 필요 조각과 기존 강화 재화인 `ElementCore`가 모두 필요하다.
- 최대 레벨 가호는 소환 풀에서 제외한다.
- 모든 가호가 최대 레벨이면 티켓을 사용할 수 없으며 티켓도 소비하지 않는다.

## 3. 용어

| 용어 | 설명 | 상태 |
|---|---|---|
| 노아의 기억 | 2·3단계 노아를 해금하는 공용 재화 | 확정 |
| 정화 가호 소환 티켓 | 가호의 제단에서 가호 1회를 소환하는 재화 | 가칭 |
| 가호의 제단 | 정화 가호를 소환하는 영구 메뉴 | 확정 |
| 가호 조각 | 동일한 가호를 중복 획득했을 때 얻는 가호별 강화 재료 | 확정 |
| ElementCore | 가호 레벨업에 사용하는 기존 공용 강화 재화 | 기존 명칭 |

`정화 가호 소환 티켓`의 최종 명칭은 별도 워딩 작업에서 결정한다. 시스템 규칙과 저장 데이터는 표시 명칭 변경의 영향을 받지 않도록 구성한다.

## 4. 노아 획득 시스템

### 4.1 기본 해금 상태

- 신규 플레이어는 모든 속성의 1단계 노아를 해금한 상태로 시작한다.
- 모든 2단계와 3단계 노아는 미해금 상태로 시작한다.
- 기존 플레이어에게 적용할 초기 해금 상태와 마이그레이션 정책은 구현 전에 별도로 결정한다.

### 4.2 노아의 기억 획득

- `노아의 기억`은 정화 보상으로 지급한다.
- 스테이지, 정화 결과 및 진행도에 따른 지급량은 별도 밸런스 데이터로 관리한다.
- MVP 기획에서는 구체적인 지급량과 노아별 해금 비용을 확정하지 않는다.

### 4.3 순차 해금 규칙

노아 해금 가능 여부는 `NoaSO.NextTierNoa`로 연결된 합성 계보를 기준으로 판단한다.

```text
1단계 노아: 기본 해금
    ↓
연결된 2단계 노아: 1단계 노아가 해금되어 있을 때 해금 가능
    ↓
연결된 3단계 노아: 2단계 노아가 해금되어 있을 때 해금 가능
```

해금 조건은 다음과 같다.

1. 대상 노아가 현재 미해금 상태여야 한다.
2. 대상 노아의 직전 단계 노아가 해금되어 있어야 한다.
3. 대상 노아에 설정된 수량 이상의 `노아의 기억`을 보유해야 한다.
4. 해금 시 필요한 `노아의 기억`을 소비하고 해금 상태를 저장한다.

선행 노아가 미해금이면 다음 단계 노아를 미리 해금하거나 선행 노아와 함께 일괄 해금할 수 없다.

### 4.4 정화 소환과 합성

- 정화 소환은 해금된 노아만 후보로 사용한다.
- 미해금 노아는 소환 확률 계산에서 완전히 제외한다.
- 합성 대상인 다음 단계 노아가 해금된 경우에만 합성할 수 있다.
- 다음 단계 노아가 미해금이면 합성 버튼을 비활성화하고 해금 필요 상태를 안내한다.
- 노아를 새로 해금하면 다음 정화부터 해당 노아가 소환 및 합성 후보에 포함된다.
- 진행 중인 정화에서 해금 상태가 변경되는 흐름은 MVP에서 제공하지 않는다.

### 4.5 노아 도감 UI

미해금 노아도 도감에서 존재와 합성 계보를 확인할 수 있어야 한다.

도감에는 다음 정보를 표시한다.

- 노아 이름, 외형, 속성, 단계
- 해금 여부
- 선행 노아
- 필요한 `노아의 기억` 수량과 현재 보유량
- 해금 후 정화 소환 및 합성이 가능하다는 안내

해금 버튼 상태는 다음과 같다.

| 상태 | 버튼 | 안내 |
|---|---|---|
| 선행 노아 미해금 | 비활성화 | 이전 단계 노아를 먼저 해금해야 합니다. |
| 기억 부족 | 비활성화 | 노아의 기억이 부족합니다. |
| 모든 조건 충족 | 활성화 | 해금 시 필요한 기억 수량 표시 |
| 이미 해금 | 숨김 또는 완료 상태 | 해금 완료 |

## 5. 정화 가호 소환 시스템

### 5.1 티켓 획득과 사용

- `정화 가호 소환 티켓`은 정화 보상으로 지급한다.
- 티켓 지급 조건과 수량은 별도 밸런스 데이터로 관리한다.
- 티켓 1개로 가호 1회를 소환한다.
- MVP에서는 10회 소환, 소환 할인 및 유료 재화 대체 사용을 제공하지 않는다.
- 정화 결과 화면에서 가호의 제단으로 이동할 수 있는 진입 버튼을 제공할 수 있다.
- 실제 소환과 가호 관리는 정화 결과 화면이 아닌 가호의 제단에서 처리한다.

### 5.2 소환 후보

다음 조건을 모두 만족하는 가호만 소환 후보가 된다.

1. 현재 콘텐츠에서 획득 가능한 가호이다.
2. 가호 레벨이 최대 레벨 미만이거나 아직 해금되지 않았다.

최대 레벨 가호는 소환 후보 및 확률 계산에서 제외한다. 최대 레벨 미만인 가호는 현재 보유 조각 수와 관계없이 소환 후보로 유지한다.

MVP에서는 소환 확률의 천장, 집중 가호 지정 및 선택 소환을 제공하지 않는다. 가호별 기본 확률과 희귀도 적용 여부는 별도 밸런스 데이터로 관리한다.

### 5.3 소환 결과

| 소환 결과 | 처리 |
|---|---|
| 미보유 가호 | 가호를 Lv.1로 해금 |
| 보유 중이며 최대 레벨 미만인 가호 | 해당 가호 조각 +1 |
| 최대 레벨 가호 | 소환 후보에서 제외되므로 등장하지 않음 |

최초 획득은 가호 해금만 처리하고 조각을 추가로 지급하지 않는다.

### 5.4 소환 불가 상태

모든 가호가 최대 레벨이면 소환 가능한 가호가 없는 상태로 판단한다.

- 소환 버튼을 비활성화한다.
- 보유 티켓은 소비하지 않는다.
- 버튼에는 `모든 가호 성장 완료` 상태를 표시한다.
- 버튼 선택 또는 안내 영역에 다음 메시지를 표시한다.

> 모든 정화 가호가 최대 레벨입니다.  
> 현재 소환 가능한 가호가 없습니다.

새로운 가호가 콘텐츠에 추가되면 해당 가호가 자동으로 소환 후보에 포함되고 소환 버튼이 다시 활성화된다.

## 6. 정화 가호 강화 시스템

### 6.1 강화 조건

가호 레벨업은 자동으로 처리하지 않는다. 플레이어가 가호 관리 화면에서 직접 레벨업을 실행한다.

레벨업에는 다음 조건이 모두 필요하다.

1. 대상 가호가 해금되어 있어야 한다.
2. 현재 레벨이 최대 레벨보다 낮아야 한다.
3. 현재 레벨에 설정된 필요 조각 수를 보유해야 한다.
4. 현재 레벨에 설정된 `ElementCore` 비용을 보유해야 한다.

레벨업 성공 시 필요 조각과 `ElementCore`를 모두 소비하고 가호 레벨을 1 올린다.

### 6.2 레벨별 요구량

현재 가호 최대 레벨인 Lv.4를 유지한다. `ElementCore` 비용은 기존 `BlessingSO.UpgradeCosts`를 사용한다.

가호 조각은 중복 소환으로만 획득하므로 낮은 획득 확률을 보정하기 위해 높은 등급일수록 필요 조각 수를 낮게 설정한다. 높은 등급의 추가 성장 비용은 기존 `ElementCore` 비용으로 유지한다.

| 등급 | Lv.1 → Lv.2 | Lv.2 → Lv.3 | Lv.3 → Lv.4 | 최대 레벨까지 총 조각 |
|---|---:|---:|---:|---:|
| 일반 | 2개 | 5개 | 9개 | 16개 |
| 희귀 | 2개 | 4개 | 7개 | 13개 |
| 에픽 | 1개 | 3개 | 5개 | 9개 |

첫 레벨업은 중복 획득 후 빠르게 경험할 수 있도록 요구량을 낮게 설정하고, 마지막 레벨업은 장기 성장 목표가 되도록 가장 많은 조각을 요구한다.

필요 조각 수는 각 `BlessingSO`에 반복 저장하지 않고 등급별 공용 성장 밸런스 데이터로 관리한다.

```text
BlessingGrowthBalance
  Common:    [2, 5, 9]
  Rare:      [2, 4, 7]
  Epic:     [1, 3, 5]
```

배열 인덱스는 현재 레벨에서 1을 뺀 값으로 사용한다. 예를 들어 희귀 가호가 Lv.2이면 `Rare[1]`에 해당하는 조각 4개가 필요하다.

### 6.3 강화 UI

가호 상세 화면에는 현재 레벨, 다음 레벨 효과, 보유 조각과 필요 조각, 보유 `ElementCore`와 필요 비용을 함께 표시한다.

```text
숲의 가호 Lv.1

가호 조각    1 / 2
ElementCore  750 / 500

[레벨업 불가]
```

두 자원 조건을 모두 만족하면 레벨업 버튼을 활성화한다.

```text
가호 조각    2 / 2
ElementCore  750 / 500

[레벨업]
```

## 7. 전체 플레이 흐름

### 노아

```text
정화 플레이
→ 노아의 기억 획득
→ 노아 도감에서 해금 가능한 다음 단계 확인
→ 원하는 노아 해금
→ 이후 정화의 소환 및 합성 후보에 추가
```

### 정화 가호

```text
정화 플레이
→ 정화 가호 소환 티켓 획득
→ 가호의 제단에서 티켓 사용
→ 신규 가호 해금 또는 보유 가호 조각 획득
→ 조각과 ElementCore 조건 충족
→ 가호 관리 화면에서 직접 레벨업
```

## 8. 저장 및 서버 검증 요구사항

보상 지급, 노아 해금, 가호 소환 및 가호 레벨업 결과는 서버를 기준으로 확정한다.

필요한 플레이어 데이터는 다음과 같다.

- `노아의 기억` 보유량
- 노아별 해금 여부
- 정화 가호 소환 티켓 보유량
- 가호별 해금 여부
- 가호별 현재 레벨
- 가호별 보유 조각 수

가호 조각은 가호 ID를 키로 사용하는 정수 맵으로 저장한다. 키가 없으면 보유량을 0개로 처리한다.

```text
BlessingPieceCounts
  blessing_cycle_stone: 4
  blessing_guardian_stone_of_earth: 1
```

서버는 다음 항목을 검증해야 한다.

- 노아 해금 시 선행 노아 해금 여부와 기억 보유량
- 가호 소환 전 티켓 보유량과 소환 가능한 가호 존재 여부
- 소환 결과가 현재 유효한 소환 풀에 포함되는지 여부
- 가호 레벨업 시 현재 레벨, 필요 조각, `ElementCore` 비용 및 최대 레벨
- 동일 요청 재전송으로 인한 티켓·재화 중복 소비 또는 보상 중복 지급 방지

가호 레벨업 시 서버는 현재 가호의 등급과 레벨을 기준으로 공용 성장 밸런스 데이터에서 필요 조각 수를 조회한다. 조건을 모두 만족하면 트랜잭션 안에서 해당 가호 조각과 `ElementCore`를 차감하고 레벨을 1 올린다.

소환 가능한 가호가 없으면 실패 결과를 반환하고 티켓을 소비하지 않는다.

## 9. MVP 제외 범위

다음 기능은 초기 MVP에서 구현하지 않는다.

- 가호 소환 천장
- 집중 가호 및 확률 상승 대상 지정
- 선택 소환
- 10회 연속 소환 및 최소 등급 보장
- 가호 조각 교환소
- 공용 가호 조각 또는 최대 레벨 중복 보상 변환
- 노아 선행 단계 일괄 해금
- 노아 해금 초기화 또는 환불

MVP 플레이 데이터에서 특정 가호 획득 편차와 노아 해금 속도를 확인한 뒤 필요한 보완 기능을 결정한다.

## 10. 밸런스 확정 및 미확정 항목

다음 수치는 `PurifyRewardBalance.md`와 서버 설정 버전 4에서 확정했다.

- 정화 결과별 `노아의 기억` 고정 지급 수량
- 2단계 노아 해금 비용 10개, 3단계 노아 해금 비용 20개
- 정화 결과별 가호 소환 티켓 고정 지급 수량

다음 수치는 아직 별도로 확정해야 한다.

- 가호별 및 희귀도별 소환 확률
- 기존 `ElementCore` 강화 비용 유지 또는 재조정 여부
- 기존 플레이어의 노아 및 가호 해금 상태 마이그레이션 정책

## 11. MVP 완료 조건

- 신규 플레이어에게 모든 1단계 노아만 기본 해금된다.
- 선행 노아가 해금된 경우에만 다음 단계 노아를 해금할 수 있다.
- 미해금 노아가 정화 소환과 합성 결과에 등장하지 않는다.
- 정화 보상으로 가호 소환 티켓을 획득할 수 있다.
- 가호의 제단에서 티켓을 사용하여 가호를 소환할 수 있다.
- 최초 가호 획득 시 Lv.1로 해금되고, 중복 획득 시 전용 조각 1개가 지급된다.
- 필요 조각과 `ElementCore`를 모두 보유한 경우에만 가호를 레벨업할 수 있다.
- 최대 레벨 가호가 소환 결과에 등장하지 않는다.
- 모든 가호가 최대 레벨이면 티켓이 소비되지 않고 소환 불가 안내가 표시된다.
